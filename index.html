03

Diabetes Risk Predictor

Built an interactive R Shiny web app that predicts diabetes risk from patient health metrics using a random forest model, with EDA-driven feature analysis and a tuned decision threshold for clinical use.

App walkthrough

Goal

Estimate diabetes risk from patient health metrics in an interactive web app.

Try it

  1. Enter the requested patient health metrics in the app.
  2. Run the prediction to see the estimated diabetes risk.
  3. Explore the feature analysis to see how health metrics relate to the result.

Model

Random forest with a tuned decision threshold.

Tools: R and Shiny
